# Anasto Project

> A Nuxt.js-based project for showcasing and managing content effectively.

## Project Overview

The Anasto Project is designed to provide a seamless user experience with a modern interface. It includes features such as:
- Dynamic routing for pages like biography and contact.
- Modular components for easy customization.
- Integration with Vuex for state management.

## Build Setup

```bash
# Install dependencies
$ npm install

# Serve with hot reload at localhost:3000
$ npm run dev

# Build for production and launch server
$ npm run build
$ npm start

# Generate static project
$ npm run generate
```

## Directory Structure

- **assets/**: Contains uncompiled assets such as CSS and images.
- **components/**: Includes reusable Vue.js components like navigation and UI elements.
- **layouts/**: Defines application layouts for consistent structure.
- **middleware/**: Contains custom functions to run before rendering pages.
- **pages/**: Holds application views and routes.
- **plugins/**: Includes JavaScript plugins to run before mounting the app.
- **static/**: Contains static files mapped directly to the root URL.
- **store/**: Implements Vuex for state management.
